Agregar proyecto nuevo

Elige el slug con cuidado (letras minúsculas, sin espacios) — es el identificador interno y no se puede cambiar después.

Así se arma el número de cada proforma de este proyecto, ej. LUMEN-0001, LUMEN-0002…

Se escriben como fracción: 2% = 0.02, 8% = 0.08, 30% = 0.30. En "Pago directo" la reserva se usa como % de abono sugerido (editable por el asesor) y la promesa no se usa.

El asesor puede cambiar la tasa y el plazo en cada proforma — esto solo define el valor con el que arranca el formulario.

Asesores (GPUnlock)

Alimenta el desplegable de "Datos del asesor" en el cotizador — al elegir un nombre ahí, el teléfono se rellena solo. Es solo un directorio de contacto, no crea cuentas de acceso (eso se hace en Supabase → Authentication → Users).
